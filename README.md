# Simple Interest Calculator

**Project name:** Simple Interest Calculator

A Bash script that computes simple interest given the principal amount,
annual rate of interest, and time period in years.

The calculator prompts the user for three inputs:

- **Principal** (`p`) — the initial amount of money
- **Rate of interest** (`r`) — annual rate in percent
- **Time period** (`t`) — duration in years

It then calculates and prints the simple interest using the formula:

```
simple interest = p * t * r / 100
```

## Usage

```bash
bash simple-interest.sh
```

Example:

```
Enter the principal:
1000
Enter rate of interest per year:
5
Enter time period in years:
2
The simple interest is:
100
```
